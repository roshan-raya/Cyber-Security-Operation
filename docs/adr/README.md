# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the Catnip Games
patch management platform.

ADRs explain why key technical decisions were made, what alternatives were considered,
and what the consequences of each decision are. They are written at the time the
decision is made and never retroactively changed — if a decision is reversed, a new
ADR supersedes the old one.
